## 实现

- `scripts/Bottle/View.lua` 当前使用 `Machine.LayeredSkin`。旧 `Machine.Skin` / Cabinet / 模型保留历史文件，但新界面不构建旧机壳场景，也不经过旧透视点击映射。
- `scripts/Machine/LayeredLayout.lua` 是统一的402×874排布坐标；按安全区等比缩放。绘制和点击共享 UI 布局坐标。
- `scripts/Machine/LayeredSkin.lua` 把底板、前后牌、屏框、数字窗、灯态、计时器和按钮组成独立 UI 层。规则、GM、存档和物理入口在右上角，保留原回调。
- `scripts/Machine/FlatReelState.lua` 保留8位前导零、逐位数字带滚动、增减分方向，以及滚动途中变更目标时的当前位置/速度。小数、负号和大数继续显示。数字窗直接二维裁切，无柱面/模型。
- 牌库及选中候选说明使用中央屏幕；三选一槽位在屏外下方，先预览再选择。计时器三次闪烁后展示候选。查看牌库时保留候选选择。物品详情限制在屏内。
- 物品图形、物理、摇晃和得分规则沿用现有模块；未把概念图中的四件水果写死成玩法。

## 资源与切割

`assets/image/machine-layered/` 共51张PNG：6张干净面板源图，5类面板各9张独立切片（45张）。运行时读取45张切片及桌面纹理，文字、图标和数字均单独绘制。

| 资源前缀 | 用途 |
|---|---|
| metal | 得分、计时、进度等灰绿面板 |
| wood | 回合、目标、牌库与重抽的棕色底板 |
| green | 主动作与当前候选底板 |
| felt | 下方深绿菱形织物底板 |
| screen | CRT薄边框与独立玻璃底纹 |
| desk | 台面纹理 |

后缀1–9为从左上到右下的九宫格；5为内部底板，其他为四角/四边。角部保持尺寸，直边伸缩；木纹和织物内部平铺。各面板可单独隐藏、移动、换材质。不是将完整截图切成带文字和水果的矩形块。

`source-sheet.png` 通过内置 image_gen 以用户确认图为参考生成，完整提示词见 `PROMPT.txt`。源结果没有可靠的透明背景；切割只保留面板矩形内部，未将其背景混入运行底图。`slice-assets.ps1` 保存实测裁切范围并最近邻降至低分辨率；`manifest.json` 记录尺寸。该过程不把生成纹理宣称为手工逐像素母版。

重导出（项目根执行）：`& art-source/machine/layered-v1/slice-assets.ps1`。
