# 固定横向机台：摇晃 / 三选一双状态

这版从用户提供的两张 Slots & Daggers 截图的**分区方式与像素绘制方法**重新设计，不以原竖机台或此前的折叠托盘效果图为底稿。效果图为方向稿：[`prepare.png`](prepare.png)、[`draft.png`](draft.png)。未改运行资源与玩法。

## 固定构图

- 16:9 横向桌面机台。中央为游戏棋盘，左侧窄列分别显示得分、目标、离散进度灯和计时；右侧有常驻的实体物品说明窗。
- 下方是一整条始终保持位置与外轮廓不变的机械栏。准备时显示当前五件物品；三选一时，同一栏内显示三个候选与两个关闭的空槽。
- 右下角为暖黄发光三角形实体键。准备态执行“开始摇晃”；三选一态用于确认当前预览候选。此版不用大红按钮。
- 所有标签、动态数值和说明文本均落在机台的面板上，随其透视。亮色只用于当前候选、少量进度灯和主箭头。

## 切换和操作

回合结束并完成计时红闪后，机台外壳不移动。下方机械栏的五个窗先由水平薄闸片遮住；内部图标带横向换位，闸片再打开，出现三个候选。右侧说明窗在这一阶段仍固定不动，只更新选中物品的名称、实时数值、冷却、标签与完整效果。棋盘停在回合末帧并略微压暗。

点候选窗先预览；再按右下角发光箭头确认并调用现有 `Choose(index)`。底部工具栏保留一次刷新、跳过，以及一个小眼睛键用于暂时隐藏选择内容；隐藏不改变候选和随机状态，主键可再次打开。候选少于三个时，空窗关闭。

视觉节奏建议：闸片闭合 90 ms → 图标带横向切换 140 ms → 闸片开放 110 ms → 选中框与说明文字更新 80 ms。候选预览只移动窗内图标与焦点光，不移动整块面板。关键操作保留短促的按压和一次回弹。

## 与现工程的关系

现工程采用 420×840 竖向布局。这套严格按参考图空间关系绘制的 16:9 效果图，若落地，需要先确认项目是否改横屏，或另外做一版竖屏重新排布；不能直接将它缩放塞进现有竖屏。此处仅供视觉和交互方向评审。
