# 竖屏中央复用机台

由 shared-center-v3 的横向方案重新排布为 9:16 手机竖屏，保持同一像素美术语言。效果图 prepare.png、draft.png，使用内置 imagegen 生成；它们是概念图，当前没有修改游戏运行资源。

从上到下：得分转轮与目标并排 → 回合标记与离散灯列 → 中央共用屏 → 倒计时窄条 → 固定物品栏 → 底部实体操作键。

准备/摇晃时中央显示棋盘；三选一时同一显示面切换为当前候选的图标、名称、现值、冷却、标签与完整效果。中央不存在独立侧边说明面板。长描述在屏面内滚动。

下方物品栏保持固定，准备态显示当前物品预览（五个图标仅为排版样例，实际数量可超过五件）；三选一态显示最多三个候选，候选不足时空窗锁闭。底部箭头在开始/确认之间切换。刷新一次、跳过、暂时隐藏保持可用，规则和存档可加在上缘小图标键上。

两个状态使用相同机身、共用屏位置、倒计时位置和底部操作键位置。状态切换仅用屏内扫光与栏内闸片水平运动，不抬起任何面板。所有文字与点击区域必须与对应面板使用相同透视变换。
